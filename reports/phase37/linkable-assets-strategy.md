# Phase 37 — Linkable Assets Strategy
**Domain:** https://jftagro.com · **Date:** 2026-08-29

> Strategy only. No website edits, no deployment. Assets listed are recommendations pending approval. Every asset must use **REAL data** — no fabricated statistics (contract §31).

## 1. Asset principles
- Build genuinely useful, citation-worthy resources for B2B buyers, traders, and industry editors.
- Prefer assets that earn *editorial* links (associations, press, research) over directory listings.
- Align with Phase 36 AI-search entity plan (structured data, consistency).

## 2. Asset categories

### A. Interactive calculators (highest leverage)
- **Packing/load calculator** (bags per container, volume/weight). *Some calculator(s) may already exist on-site — verify before building.*
- **Port-transit estimator** (route → ETA/cost band). Use REAL route/logistics data.
- **Indicative quote/RFQ helper** (product + volume → contact sales). No live pricing claims unless REAL.
- *Citation potential:* logistics blogs, trade guides, buyer resources.

### B. Original commodity data resources
- Export-readiness / HS-code guides per product (rice, spices, pulses, grains).
- Seasonal availability / sourcing calendar (REAL sourcing windows only).
- *Citation potential:* commodity boards, trade press, university extension.

### C. B2B / buyer guides
- "How to import [product] from India" — procedural, compliant, non-promotional.
- Incoterms / documentation checklists (use standard, accurate trade definitions).
- *Citation potential:* chambers of commerce, export consultants, directories.

### D. Original research (long-term, highest authority)
- Annual "Indian agri-export indicators" using **published government data** (APEDA/DGFT aggregates) — clearly attributed, no invented numbers.
- *Citation potential:* press, associations, academia.

## 3. Required evidence per asset (must be REAL)
| Asset | Required real evidence |
|---|---|
| Calculators | Real logistics routes, real container specs, verified product weights |
| Commodity guides | Real HS codes, real export regulations, real product specs |
| Research | Published government/industry datasets; explicit attribution |

## 4. Anchor-text safety
- Use branded / natural anchors only ("jftagro", "jftagro.com", naked URL, descriptive phrases).
- No exact-match commercial anchor campaigns.
