# SEO Implementation Phase 5 — 20 August 2026

## Outcome

This phase addressed opportunity-map ranks 19–23: 100% broken rice, 5% and 25% silky sortex white rice, PR11 rice and Samba rice.

## Implemented work

### Broken rice

- Removed fixed-port, broad certification and implied end-use suitability language from the search description and buyer section.
- Required intended use, base-rice identity, food/feed status, testing scope and destination rules in the buyer workflow.
- Linked the page to the IR64 grade guide and the current APEDA/DGFT rice-notification index.
- Made current export-policy verification explicit because broken-rice conditions have changed over time.

### 5% and 25% silky sortex white rice

- Added “rice” to each primary title and H1 so the page topic is explicit.
- Explained that broken percentage, silky finish and sortex processing are separate specification fields and do not identify the base variety.
- Removed unsupported Africa/Asia and institutional-buyer assertions.
- Added reciprocal contextual links so buyers can compare 5% and 25% offers using the same base rice, packing, inspection and document assumptions.

### PR11 rice

- Removed unsupported Punjab, market and grain-preference statements.
- Required variety-identity evidence, origin declaration, processing form, measurable quality fields and an approved cooking sample.
- Added direct paths to the purchase-specification and COA guides.

### Samba rice

- Removed unsupported regional, diaspora and culinary targeting.
- Explained that “Samba” alone can be an incomplete trade description.
- Used ICAR’s Samba Mahsuri/BPT 5204 reference to explain why buyers should not assume every Samba offer has that identity.
- Added a direct path to the purchase-specification guide.
