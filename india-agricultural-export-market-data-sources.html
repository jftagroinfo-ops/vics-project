Indian Agricultural Export Market Data Sources

A buyer and analyst directory of official portals for trade value, quantity, destination, spice exports, domestic mandi prices and export-policy checks. Reviewed 20 August 2026; always inspect the live portal metadata before using a figure.

Download the CSV dataset
Use the correct dataset for the question. Export value is not supplier revenue, domestic mandi price is not an FOB quotation, a partial financial year is not comparable with a completed year, and an authority's product grouping may not equal an HS-code selection.

Methodology and reuse

  1. Only official government/statutory-source portals were included in this first edition.
  2. Each portal was reviewed for observable dimensions, intended analytical use and a material interpretation risk.
  3. No values from different sources were merged into a new market-size estimate.
  4. The CSV records the review date and should be versioned when a portal, period or definition changes.
